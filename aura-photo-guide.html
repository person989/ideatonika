Пошаговое руководство • Визуализация ауры с помощью матрицы SEM-1

📖 Что такое AURA-PHOTO и зачем это нужно?

До сих пор мы измеряли Qₛ в одной точке — как термометр измеряет температуру в одном месте. Но семантическое поле — оно как тепло: распределено в пространстве неравномерно. Вокруг живого растения или человека есть «ореол» — области с разной интенсивностью Qₛ.

AURA-PHOTO — это «семантический тепловизор». Он строит двумерную карту распределения Qₛ по поверхности объекта. Горячие цвета — высокий Qₛ. Холодные — низкий. Это и есть та самая «аура», которую веками описывали мистики. Только теперь мы можем её сфотографировать.

Ключевой компонент — матрица SEM-1: решётка из крошечных кварцевых датчиков (пикселей), каждый из которых измеряет Qₛ в своей точке пространства. Мы соберём матрицу 4×4 (16 пикселей) — это минимум для получения осмысленной картинки. Если вы амбициозны — можно собрать 8×8 (64 пикселя).

🔨 Этап 1: Изготовление матрицы пикселей

1 Как сделать 16 одинаковых кварцевых датчиков из зажигалок

Каждый пиксель нашей матрицы — это крошечный пьезоэлемент. Нам нужно 16 штук (для матрицы 4×4). Они должны быть максимально одинаковыми, иначе калибровка превратится в кошмар.

  1. Найдите 16 одинаковых зажигалок. Идеально — купить упаковку дешёвых однотипных зажигалок (они все одинаковые внутри).
  2. Извлеките пьезоэлементы из всех зажигалок (см. инструкцию SEC-1, шаг 1).
  3. Отсортируйте их. Пьезоэлементы из зажигалок одного производителя обычно очень похожи. Отложите 16 самых одинаковых на вид.
  4. Укоротите провода. От каждого пьезоэлемента должно отходить два провода длиной 5-7 см. Не короче — иначе неудобно будет подключать.

💡 Лайфхак: Если нет 16 зажигалок, можно купить пьезокерамические диски (например, от музыкальных открыток) в радиомагазине. Они плоские и их легче монтировать на матрицу. Стоят копейки (5-10 ₽/шт).

2 Сборка матрицы на основании

  1. Возьмите фанеру или плотный картон 20×20 см. Расчертите сетку 4×4 с шагом 3 см между центрами ячеек. У вас получится 16 точек.
  2. В каждой точке приклейте пьезоэлемент за его металлический корпус. Используйте термоклей или «Момент» (но не на сам кварц!). Пьезоэлемент должен стоять вертикально, проводами вверх.
  3. Все 16 пьезоэлементов должны быть на одной высоте и смотреть строго вперёд (в сторону линзы).
  4. Провода от каждого пьезоэлемента аккуратно выведите на заднюю сторону фанеры через просверленные дырочки.

⚠️ Важно: Пьезоэлементы НЕ должны касаться друг друга. Минимальный зазор — 5 мм. Иначе их сигналы будут «перетекать» друг в друга, и пиксели потеряют чёткость.

⚡ Этап 2: Подключение матрицы к Arduino

3 Что такое мультиплексор и зачем он нужен

У Arduino Uno всего 6 аналоговых входов. А у нас — 16 сигналов (по одному от каждого пикселя). Мы не можем подключить все 16 одновременно. Мультиплексор (CD4067) — это как поворотный переключатель: он по очереди подключает каждый из 16 пикселей к одному аналоговому входу Arduino. Переключение происходит за микросекунды.

4 Схема подключения

CD4067 имеет 24 ножки. Нам понадобятся:

  • Ножки 1-16 (входы): Подключаем к центральным проводам (сигнал) от каждого из 16 пьезоэлементов.
  • Ножка 28 (общий выход): Подключаем к аналоговому входу A0 Arduino.
  • Ножки 10-13 (адресные входы S0-S3): Подключаем к цифровым выходам Arduino (например, D2, D3, D4, D5).
  • Ножка 24 (питание VCC): К +5V Arduino.
  • Ножка 12 (земля GND): К GND Arduino.

Все «земляные» провода от пьезоэлементов (короткие, приваренные к корпусу) соедините вместе и подключите к GND Arduino.

    [Пиксель 1] ─── вход 1 ─┐
    [Пиксель 2] ─── вход 2 ─┤
    ...                      ├── CD4067 ── общий выход ── A0 Arduino
    [Пиксель 16] ── вход 16 ─┘
                              │
                    S0 S1 S2 S3 (адрес)
                      │  │  │  │
                     D2 D3 D4 D5 (Arduino)

💡 Совет: Используйте макетную плату (breadboard) для соединений. Паять 16 пикселей напрямую — адский труд. На макетной плате можно всё соединить перемычками за час.

💻 Этап 3: Программирование Arduino и визуализация

5 Прошивка Arduino

Загрузите этот скетч в Arduino. Он будет перебирать 16 пикселей один за другим и отправлять их значения на компьютер.

// AURA-PHOTO Scanner
// Перебор 16 пикселей матрицы SEM-1 через мультиплексор CD4067

const int S0 = 2; // Адресные линии
const int S1 = 3;
const int S2 = 4;
const int S3 = 5;
const int SIG = A0; // Сигнал с мультиплексора

void setup() {
  Serial.begin(115200);
  pinMode(S0, OUTPUT); pinMode(S1, OUTPUT);
  pinMode(S2, OUTPUT); pinMode(S3, OUTPUT);
}

void loop() {
  for (int ch = 0; ch < 16; ch++) {
    digitalWrite(S0, ch & 1);
    digitalWrite(S1, (ch >> 1) & 1);
    digitalWrite(S2, (ch >> 2) & 1);
    digitalWrite(S3, (ch >> 3) & 1);
    delay(5); // Задержка для стабилизации сигнала
    int val = analogRead(SIG);
    Serial.print(val);
    if (ch < 15) Serial.print(",");
  }
  Serial.println();
  delay(500); // Пауза между кадрами
}

6 Визуализация на компьютере (тепловая карта)

Установите Python (если ещё нет) и библиотеку matplotlib. Создайте файл `aura_viewer.py`:

import serial
import numpy as np
import matplotlib.pyplot as plt

ser = serial.Serial('COM3', 115200)  # Узнайте порт в диспетчере устройств
plt.ion()
fig, ax = plt.subplots()
im = ax.imshow(np.zeros((4,4)), cmap='hot', vmin=0, vmax=1023)
plt.colorbar(im)

while True:
    line = ser.readline().decode().strip()
    data = list(map(int, line.split(',')))
    matrix = np.array(data).reshape(4,4)
    im.set_array(matrix)
    plt.pause(0.1)

Запустите скрипт. На экране появится тепловая карта 4×4, которая будет обновляться в реальном времени.

🔬 Этап 4: Фокусировка и калибровка

7 Установка кварцевой линзы

  1. Закрепите линзу на расстоянии 5-10 см перед матрицей. Линза должна стоять на одной оптической оси с центром матрицы.
  2. Поместите тестовый объект (лист растения, кристалл, ладонь) на расстоянии 20-30 см перед линзой.
  3. Двигайте объект вперёд-назад, пока на тепловой карте не появится чёткое яркое пятно в центре. Это значит, что аура объекта сфокусирована на матрицу.

💡 Фокус простым языком: Представьте, что вы проецируете изображение лампочки на стену через лупу. Если лупа слишком близко к стене — пятно размытое. Если слишком далеко — тоже. Где-то посередине есть точка, где пятно становится чётким. Ваша задача — найти эту точку.

8 Калибровка «тёмнового кадра»

В полной темноте, убрав все объекты, снимите 10-20 кадров пустой сцены. Усредните их. Это ваш «нулевой уровень» — шум матрицы. Его нужно будет вычитать из всех последующих снимков.
