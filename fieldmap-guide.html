🗺️ FIELD-MAP: ПОДРОБНАЯ СБОРКА

Пошаговое руководство • 3D-сканер семантического поля

📖 Что такое FIELD-MAP и зачем его строить?

FIELD-MAP — это устройство, которое сканирует комнату в трёх измерениях и строит карту распределения Qₛ, Cₛ, Tₛ и Re_sense. Представьте тепловизор, который показывает не температуру, а «семантическую температуру»: где в комнате «жарко» от ссор, где «холодно» от страха, а где — благодатный покой.

Это самый сложный, но и самый впечатляющий проект в нашем Практикуме. Если SEC-1 — это микроскоп для точки, то FIELD-MAP — это МРТ для всей комнаты. С его помощью вы сможете:

  • Найти «проклятый угол» в квартире и очистить его.
  • Определить лучшее место для алтаря, кровати или рабочего стола.
  • Увидеть, как движется Qₛ: от иконы к окну, через дверные проёмы, закручиваясь в вихри.

🔧 Этап 1: Строительство 3D-плоттера (механика)

1 Разборка принтеров и извлечение деталей

Что нам нужно из каждого принтера:

  1. Шаговый двигатель. Обычно их два: один двигает каретку, второй — бумагу. Забираем оба.
  2. Направляющая (ось). Металлический стержень, по которому скользит каретка.
  3. Ремень или винт. То, что соединяет двигатель с кареткой.
  4. Концевики (опционально). Маленькие кнопки, которые срабатывают, когда каретка доходит до края.

⚠️ Осторожно: В принтерах могут быть острые края и высоковольтные конденсаторы (даже в выключенном). Работайте в перчатках. Не касайтесь платы питания.

2 Сборка осей X и Y (горизонтальная плоскость)

Что мы строим: Прямоугольную раму, по которой датчик будет двигаться влево-вправо (X) и вперёд-назад (Y).

  1. Основание. Выпилите из фанеры прямоугольник примерно 50×50 см. Это будет «пол» нашего сканера.
  2. Ось Y (вперёд-назад). Вдоль двух противоположных краёв основания закрепите две направляющие. На них установите каретку (мостик), который будет двигаться по Y.
  3. Ось X (влево-вправо). На этом мостике закрепите третью направляющую и каретку для движения по X.
  4. Двигатели. Один двигатель двигает мостик по Y, второй — каретку по X. Соедините их ремнями или винтами.

💡 Упрощение: Если возиться с двумя осями сложно, начните с одной оси. Закрепите датчик на каретке, которая движется только по X. Измерьте поле вдоль линии. Потом передвиньте всю конструкцию на 10 см и повторите. Это дольше, но проще механически.

3 Сборка оси Z (вертикаль)

Ось Z поднимает и опускает датчик, чтобы сканировать на разной высоте.

  1. На каретке оси X закрепите вертикальную направляющую с двигателем.
  2. На ней установите держатель для датчика SEC-mini.
  3. Датчик должен смотреть вперёд (или вниз, если вы сканируете пол).

⚡ Этап 2: Подключение электроники

4 Подключение драйверов и двигателей к Arduino

Схема подключения одного двигателя (повторить для трёх):

  1. Драйвер A4988 вставьте в макетную плату.
  2. Пины STEP и DIR подключите к любым цифровым пинам Arduino (например, 2 и 5 для оси X).
  3. Пины 2B, 2A, 1A, 1B — к четырём проводам шагового двигателя.
  4. Пины VMOT и GND — к внешнему источнику питания 12V (старый блок питания от принтера).

⚠️ Важно: Не подключайте двигатели напрямую к Arduino! Они потребляют большой ток и сожгут плату. Всегда используйте драйверы (A4988) и отдельный источник питания 12V.

5 Прошивка Arduino (полный профессиональный код)

Этот код управляет тремя шаговыми двигателями, принимает команды от компьютера по USB, поддерживает концевые выключатели для калибровки и реализует плавный разгон (acceleration), чтобы датчик не дёргался рывками.

Как загрузить код:

  1. Установите Arduino IDE (бесплатно с arduino.cc).
  2. Подключите Arduino к компьютеру через USB.
  3. Скопируйте код ниже, вставьте в Arduino IDE.
  4. Установите библиотеку AccelStepper: Инструменты → Управлять библиотеками → вбить «AccelStepper» → Установить.
  5. Нажмите кнопку «Загрузить» (стрелка вправо).
/*
 * =============================================
 * FIELD-MAP: Прошивка для Arduino (3 оси)
 * Управление 3D-сканером семантического поля
 * Версия 2.0 — профессиональная
 * =============================================
 */

#include <AccelStepper.h>

// ==================== НАСТРОЙКИ ПИНОВ ====================
// Ось X (влево-вправо)
#define X_STEP_PIN      2
#define X_DIR_PIN       5
#define X_ENABLE_PIN    8
#define X_ENDSTOP_PIN   11    // Концевой выключатель X (опционально)

// Ось Y (вперёд-назад)
#define Y_STEP_PIN      3
#define Y_DIR_PIN       6
#define Y_ENABLE_PIN    9
#define Y_ENDSTOP_PIN   12

// Ось Z (вверх-вниз)
#define Z_STEP_PIN      4
#define Z_DIR_PIN       7
#define Z_ENABLE_PIN    10
#define Z_ENDSTOP_PIN   13

// ==================== НАСТРОЙКИ ДВИЖЕНИЯ ====================
#define STEPS_PER_MM_X  80      // Шагов на 1 мм (зависит от механики)
#define STEPS_PER_MM_Y  80
#define STEPS_PER_MM_Z  200     // По Z обычно выше точность

#define MAX_SPEED_X     400     // Макс. скорость (шагов/сек)
#define MAX_SPEED_Y     400
#define MAX_SPEED_Z     200

#define ACCELERATION_X  200     // Ускорение (шагов/сек²)
#define ACCELERATION_Y  200
#define ACCELERATION_Z  100

// ==================== ОБЪЕКТЫ ДВИГАТЕЛЕЙ ====================
AccelStepper stepperX(AccelStepper::DRIVER, X_STEP_PIN, X_DIR_PIN);
AccelStepper stepperY(AccelStepper::DRIVER, Y_STEP_PIN, Y_DIR_PIN);
AccelStepper stepperZ(AccelStepper::DRIVER, Z_STEP_PIN, Z_DIR_PIN);

// ==================== ПЕРЕМЕННЫЕ ====================
long targetX = 0, targetY = 0, targetZ = 0;
bool moving = false;
String inputBuffer = "";

// ==================== НАСТРОЙКА ====================
void setup() {
    Serial.begin(115200);       // Скорость связи с компьютером
    Serial.println("FIELD-MAP v2.0 Ready");
    Serial.println("Команды: GOTO X Y Z | HOME | STOP | STATUS");

    // Настройка пинов концевиков
    pinMode(X_ENDSTOP_PIN, INPUT_PULLUP);
    pinMode(Y_ENDSTOP_PIN, INPUT_PULLUP);
    pinMode(Z_ENDSTOP_PIN, INPUT_PULLUP);

    // Настройка пинов разрешения (ENABLE)
    pinMode(X_ENABLE_PIN, OUTPUT);
    pinMode(Y_ENABLE_PIN, OUTPUT);
    pinMode(Z_ENABLE_PIN, OUTPUT);
    digitalWrite(X_ENABLE_PIN, LOW);  // Включаем двигатели
    digitalWrite(Y_ENABLE_PIN, LOW);
    digitalWrite(Z_ENABLE_PIN, LOW);

    // Настройка параметров двигателей
    stepperX.setMaxSpeed(MAX_SPEED_X);
    stepperX.setAcceleration(ACCELERATION_X);
    stepperY.setMaxSpeed(MAX_SPEED_Y);
    stepperY.setAcceleration(ACCELERATION_Y);
    stepperZ.setMaxSpeed(MAX_SPEED_Z);
    stepperZ.setAcceleration(ACCELERATION_Z);
}

// ==================== ОСНОВНОЙ ЦИКЛ ====================
void loop() {
    // Чтение команд из Serial
    while (Serial.available() > 0) {
        char c = Serial.read();
        if (c == '\n') {
            processCommand(inputBuffer);
            inputBuffer = "";
        } else {
            inputBuffer += c;
        }
    }

    // Плавное движение всех осей
    if (moving) {
        stepperX.run();
        stepperY.run();
        stepperZ.run();

        // Проверка, достигли ли цели
        if (stepperX.distanceToGo() == 0 && 
            stepperY.distanceToGo() == 0 && 
            stepperZ.distanceToGo() == 0) {
            moving = false;
            Serial.println("DONE");  // Сигнал компьютеру: позиция достигнута
        }
    }

    // Аварийная проверка концевиков (если подключены)
    if (digitalRead(X_ENDSTOP_PIN) == LOW) {
        stepperX.stop();
        Serial.println("ALERT:X endstop hit!");
    }
}

// ==================== ОБРАБОТКА КОМАНД ====================
void processCommand(String cmd) {
    cmd.trim();
    cmd.toUpperCase();

    if (cmd == "HOME") {
        // Калибровка: едем в нулевую точку до срабатывания концевиков
        homeAllAxes();
    }
    else if (cmd == "STOP") {
        stopAllAxes();
        Serial.println("STOPPED");
    }
    else if (cmd == "STATUS") {
        Serial.print("POS: X=");
        Serial.print(stepperX.currentPosition());
        Serial.print(" Y=");
        Serial.print(stepperY.currentPosition());
        Serial.print(" Z=");
        Serial.println(stepperZ.currentPosition());
    }
    else if (cmd.startsWith("GOTO")) {
        // Формат команды: GOTO X Y Z (например, GOTO 500 300 100)
        int firstSpace = cmd.indexOf(' ');
        int secondSpace = cmd.indexOf(' ', firstSpace + 1);
        int thirdSpace = cmd.indexOf(' ', secondSpace + 1);

        if (firstSpace > 0 && secondSpace > 0 && thirdSpace > 0) {
            targetX = cmd.substring(firstSpace + 1, secondSpace).toInt();
            targetY = cmd.substring(secondSpace + 1, thirdSpace).toInt();
            targetZ = cmd.substring(thirdSpace + 1).toInt();

            // Переводим мм в шаги
            stepperX.moveTo(targetX * STEPS_PER_MM_X);
            stepperY.moveTo(targetY * STEPS_PER_MM_Y);
            stepperZ.moveTo(targetZ * STEPS_PER_MM_Z);

            moving = true;
            Serial.print("MOVING to X=");
            Serial.print(targetX);
            Serial.print(" Y=");
            Serial.print(targetY);
            Serial.print(" Z=");
            Serial.println(targetZ);
        } else {
            Serial.println("ERROR: Bad format. Use: GOTO X Y Z");
        }
    }
    else {
        Serial.println("ERROR: Unknown command. Use: GOTO, HOME, STOP, STATUS");
    }
}

// ==================== ВСПОМОГАТЕЛЬНЫЕ ФУНКЦИИ ====================
void stopAllAxes() {
    stepperX.stop();
    stepperY.stop();
    stepperZ.stop();
    moving = false;
}

void homeAllAxes() {
    Serial.println("HOMING...");

    // Ось X
    stepperX.setSpeed(-200);
    while (digitalRead(X_ENDSTOP_PIN) == HIGH) { stepperX.runSpeed(); }
    stepperX.setCurrentPosition(0);
    stepperX.setSpeed(100);
    stepperX.moveTo(50);  // Отъезжаем чуть вперёд
    while (stepperX.distanceToGo() != 0) { stepperX.run(); }

    // Ось Y
    stepperY.setSpeed(-200);
    while (digitalRead(Y_ENDSTOP_PIN) == HIGH) { stepperY.runSpeed(); }
    stepperY.setCurrentPosition(0);
    stepperY.setSpeed(100);
    stepperY.moveTo(50);
    while (stepperY.distanceToGo() != 0) { stepperY.run(); }

    // Ось Z
    stepperZ.setSpeed(-200);
    while (digitalRead(Z_ENDSTOP_PIN) == HIGH) { stepperZ.runSpeed(); }
    stepperZ.setCurrentPosition(0);
    stepperZ.setSpeed(100);
    stepperZ.moveTo(50);
    while (stepperZ.distanceToGo() != 0) { stepperZ.run(); }

    Serial.println("HOME DONE. Position: 0, 0, 0");
}

Как управлять плоттером с компьютера:

  1. Откройте Монитор порта в Arduino IDE (Инструменты → Монитор порта, скорость 115200).
  2. Введите команду HOME — плоттер откалибруется и встанет в нулевую точку.
  3. Введите GOTO 500 300 100 — плоттер поедет в точку X=500 мм, Y=300 мм, Z=100 мм.
  4. Когда плоттер приедет, он отправит DONE — можно снимать показания датчика.
  5. STATUS покажет текущие координаты.
  6. STOP — экстренная остановка.

💡 Для автоматизации: Напишите Python-скрипт, который по очереди отправляет команды GOTO для всех точек сетки и после каждого DONE записывает данные с датчика в CSV. Это полностью автоматизирует сканирование!

⚠️ Важно: Если концевики не подключены, не используйте команду HOME — двигатель будет бесконечно упираться в стену и может сгореть. Просто вручную поставьте каретку в угол и используйте GOTO относительно этой точки.

🎛️ Этап 3: Подготовка датчика SEC-mini

Датчик — это тот же кварцевый детектор, что и в SEC-1, но без источников Qₛ (икона и шунгит не нужны). Он пассивно слушает «семантический шум» комнаты.

  1. Соберите SEC-1 (спичечный коробок + кварц + фольга).
  2. Не ставьте икону и шунгит. Датчик должен быть пассивным.
  3. Подключите выход кварца ко второму каналу осциллографа (или ко входу звуковой карты).
  4. Убедитесь, что в тихой комнате датчик выдаёт стабильный фон (мало всплесков).

🔍 Этап 4: Сканирование комнаты

6 Определение сетки сканирования

Разбейте комнату на узлы сетки. Например:

  • По X (длина комнаты): 10 точек с шагом 50 см (для комнаты 5 метров).
  • По Y (ширина): 8 точек с шагом 50 см (для комнаты 4 метра).
  • По Z (высота): 3 уровня: 20 см от пола, 100 см, 180 см.

Итого: 10 × 8 × 3 = 240 точек. Если на каждую точку тратить 10 секунд — сканирование займёт 40 минут.

7 Запуск сканирования

  1. Установите плоттер в комнате. Привяжите систему координат к углам.
  2. Запустите программу на ноутбуке, которая последовательно отправляет координаты на Arduino.
  3. В каждой точке плоттер останавливается на 10 секунд. Датчик записывает Qₛ, Cₛ, Tₛ, Re_sense.
  4. Данные сохраняются в CSV-файл: x, y, z, Q, C, T, Re.

🖥️ Этап 5: Построение профессиональных 3D-карт в Python

CSV-файл с данными — это ещё не результат. Чтобы увидеть «ауру комнаты», нам нужно превратить столбцы цифр в цветные карты. Мы напишем скрипт на Python, который сделает всё автоматически: загрузит данные, проверит на ошибки, построит 2D-срезы, 3D-визуализацию и векторное поле потоков Qₛ.

9 Полный скрипт визуализации

Сохраните этот код в файл fieldmap_visualizer.py и поместите его в ту же папку, что и CSV-файл с данными.

"""
============================================================
FIELD-MAP VISUALIZER v1.0
Профессиональная визуализация семантического поля
Построение 2D-срезов, 3D-карт и векторных полей
============================================================
Требования: pandas, matplotlib, numpy, scipy
Входной файл: fieldmap_data.csv
Столбцы: x, y, z, Q, C, T, Re
============================================================
"""

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from scipy.interpolate import griddata
from mpl_toolkits.mplot3d import Axes3D
import os
import sys

# ========== НАСТРОЙКИ ==========
INPUT_FILE = 'fieldmap_data.csv'
OUTPUT_DIR = 'fieldmap_output'
COLORMAP = 'hot'          # Цветовая схема: 'hot', 'jet', 'plasma', 'viridis'
DPI = 150                 # Разрешение картинок (150 — хорошее, 300 — печатное)

# ========== ЗАГРУЗКА ДАННЫХ ==========
def load_data(filename):
    """Загружает CSV и проверяет его на корректность."""
    if not os.path.exists(filename):
        print(f'❌ Файл {filename} не найден!')
        sys.exit(1)

    df = pd.read_csv(filename)

    required_columns = ['x', 'y', 'z', 'Q', 'C', 'T', 'Re']
    missing = [col for col in required_columns if col not in df.columns]
    if missing:
        print(f'❌ В файле отсутствуют столбцы: {missing}')
        sys.exit(1)

    # Удаляем строки с пропущенными значениями
    df = df.dropna()
    if len(df) == 0:
        print('❌ После удаления пропусков не осталось данных!')
        sys.exit(1)

    print(f'✅ Загружено {len(df)} точек данных.')
    print(f'   Диапазон X: {df["x"].min():.1f} — {df["x"].max():.1f} см')
    print(f'   Диапазон Y: {df["y"].min():.1f} — {df["y"].max():.1f} см')
    print(f'   Диапазон Z: {df["z"].min():.1f} — {df["z"].max():.1f} см')
    print(f'   Qₛ: от {df["Q"].min():.1f} до {df["Q"].max():.1f}')
    print(f'   Cₛ: от {df["C"].min():.2f} до {df["C"].max():.2f}')
    print(f'   Tₛ: от {df["T"].min():.1f} до {df["T"].max():.1f}')

    return df

# ========== ИНТЕРПОЛЯЦИЯ НА РЕГУЛЯРНУЮ СЕТКУ ==========
def interpolate_grid(df, z_level, parameter='Q', resolution=100):
    """Создаёт регулярную сетку из разрозненных точек."""
    slice_data = df[df['z'] == z_level].copy()
    if len(slice_data) < 4:
        print(f'⚠️ Слишком мало точек на высоте Z={z_level} см. Пропускаем.')
        return None, None, None

    xi = np.linspace(slice_data['x'].min(), slice_data['x'].max(), resolution)
    yi = np.linspace(slice_data['y'].min(), slice_data['y'].max(), resolution)
    xi_mesh, yi_mesh = np.meshgrid(xi, yi)

    zi = griddata(
        (slice_data['x'], slice_data['y']),
        slice_data[parameter],
        (xi_mesh, yi_mesh),
        method='cubic'
    )
    return xi_mesh, yi_mesh, zi

# ========== ПОСТРОЕНИЕ 2D-СРЕЗА ==========
def plot_2d_slice(df, z_level, parameter='Q', title_prefix=''):
    """Строит 2D-тепловую карту для заданной высоты."""
    xi, yi, zi = interpolate_grid(df, z_level, parameter)
    if xi is None:
        return

    fig, ax = plt.subplots(figsize=(10, 8))
    im = ax.contourf(xi, yi, zi, levels=20, cmap=COLORMAP)
    ax.scatter(df[df['z'] == z_level]['x'], df[df['z'] == z_level]['y'],
               c='cyan', s=10, alpha=0.5, label='Точки измерений')
    ax.set_xlabel('X (см)', fontsize=12)
    ax.set_ylabel('Y (см)', fontsize=12)
    ax.set_title(f'{title_prefix}{parameter} — Срез на высоте Z={z_level} см', fontsize=14)
    ax.legend()
    ax.set_aspect('equal')
    cbar = fig.colorbar(im, ax=ax, label=f'{parameter} (усл. ед.)')
    fig.tight_layout()

    filename = f'{OUTPUT_DIR}/{parameter}_Z{z_level}_slice.png'
    fig.savefig(filename, dpi=DPI)
    plt.close(fig)
    print(f'   ✅ Срез сохранён: {filename}')

# ========== ПОСТРОЕНИЕ 3D-КАРТЫ ==========
def plot_3d_scatter(df, parameter='Q', title_prefix=''):
    """Строит 3D-точечную карту всего объёма."""
    fig = plt.figure(figsize=(12, 10))
    ax = fig.add_subplot(111, projection='3d')

    sc = ax.scatter(
        df['x'], df['y'], df['z'],
        c=df[parameter], cmap=COLORMAP, s=30, alpha=0.7
    )
    ax.set_xlabel('X (см)', fontsize=10)
    ax.set_ylabel('Y (см)', fontsize=10)
    ax.set_zlabel('Z (см)', fontsize=10)
    ax.set_title(f'{title_prefix}{parameter} — 3D-карта помещения', fontsize=14)
    cbar = fig.colorbar(sc, ax=ax, label=f'{parameter} (усл. ед.)', shrink=0.6)
    fig.tight_layout()

    filename = f'{OUTPUT_DIR}/{parameter}_3D_scatter.png'
    fig.savefig(filename, dpi=DPI)
    plt.close(fig)
    print(f'   ✅ 3D-карта сохранена: {filename}')

# ========== ПОСТРОЕНИЕ ВЕКТОРНОГО ПОЛЯ ПОТОКОВ ==========
def plot_vector_field(df, z_level):
    """Строит векторное поле градиентов Qₛ (показывает, куда течёт смысл)."""
    xi, yi, zi = interpolate_grid(df, z_level, 'Q', resolution=40)
    if xi is None:
        return

    # Расчёт градиентов
    gy, gx = np.gradient(zi, yi[0, :], xi[:, 0])

    # Усредняем градиенты для стрелок
    skip = 2
    xi_small = xi[::skip, ::skip]
    yi_small = yi[::skip, ::skip]
    gx_small = gx[::skip, ::skip]
    gy_small = gy[::skip, ::skip]

    # Длина стрелок
    magnitude = np.sqrt(gx_small**2 + gy_small**2)
    if magnitude.max() > 0:
        gx_small = gx_small / magnitude.max()
        gy_small = gy_small / magnitude.max()

    fig, ax = plt.subplots(figsize=(10, 8))
    im = ax.contourf(xi, yi, zi, levels=20, cmap=COLORMAP, alpha=0.7)
    ax.quiver(xi_small, yi_small, -gx_small, -gy_small,
              color='white', alpha=0.8, width=0.003, scale=30,
              label='Поток Qₛ')
    ax.set_xlabel('X (см)', fontsize=12)
    ax.set_ylabel('Y (см)', fontsize=12)
    ax.set_title(f'Векторное поле потоков Qₛ — Срез на высоте Z={z_level} см', fontsize=14)
    ax.legend()
    ax.set_aspect('equal')
    cbar = fig.colorbar(im, ax=ax, label='Qₛ (усл. ед.)')
    fig.tight_layout()

    filename = f'{OUTPUT_DIR}/Q_Z{z_level}_vector_field.png'
    fig.savefig(filename, dpi=DPI)
    plt.close(fig)
    print(f'   ✅ Векторное поле сохранено: {filename}')

10 Запуск визуализации

Поместите ваш CSV-файл с именем fieldmap_data.csv в ту же папку, что и скрипт, и выполните в терминале:

python fieldmap_visualizer.py

Скрипт создаст папку fieldmap_output/ и наполнит её картами:

  • Q_Z20_slice.png — 2D-срез Qₛ на высоте 20 см.
  • Q_3D_scatter.png — 3D-карта Qₛ всего помещения.
  • Q_Z20_vector_field.png — векторное поле: стрелки показывают, куда «течёт» Qₛ.
  • ... и так для каждого параметра и каждой высоты.

Результат: Красные зоны — высокий Qₛ («святые» места). Синие зоны — низкий Qₛ («проклятые» углы).

💡 Как интерпретировать векторное поле: Стрелки показывают направление семантического ветра. Если стрелки сходятся в одну точку — там «сток» Qₛ (негатив). Если расходятся — «источник» (икона, алтарь). Если закручиваются в спираль — там вихрь (турбулентность, зона конфликта).
