📻 S-RADIO: ПОДРОБНАЯ ИНСТРУКЦИЯ

Как собрать устройство для преобразования мысли в речь

📖 О чём это устройство и зачем его собирать

Каждая мысль генерирует уникальный семантический паттерн — «частотный портрет» идеи (§130). Мысль о яблоке имеет одну доминирующую частоту ω_s, мысль о доме — другую, мысль о матери — третью. S-RADIO — это устройство, которое улавливает эти паттерны через матрицу кварцевых датчиков (SEC-mini), анализирует спектр и произносит слово, соответствующее текущей мысли оператора.

Это первый шаг к телепатическому интерфейсу — возможности общаться без слов, управлять техникой силой мысли, помогать парализованным людям. И, конечно, это самое прямое доказательство того, что мысль материальна и имеет измеримые физические характеристики.

Время на сборку: 3–5 часов (если есть опыт пайки). Время на калибровку: 1–2 часа на каждое слово.

🔨 Этап 1: Подготовка компонентов

1 Изготовление кварцевых датчиков (SEC-mini)

Каждый датчик — это крошечная кварцевая пластина с припаянными проводами. Важно: кварц — пьезоэлектрик. При деформации (в том числе от семантического давления P_sense) он генерирует напряжение.

  1. Аккуратно извлеките кварцевые пластины из пьезозажигалок (или купите готовые).
  2. К каждой пластине припаяйте тонкие провода (лучше экранированные).
  3. Оберните боковые грани фольгой (заземлите фольгу — это экран).
  4. Закрепите датчики веером на диэлектрической подложке (кусок пластика или картона) с углом обзора ~120°.

💡 Совет: Если нет кварцевых пластин, используйте пьезоизлучатели (зуммеры) от старых открыток или часов. Они грубее, но для первых опытов подойдут.

2 Сборка схемы на макетной плате

Подключите компоненты по следующей схеме:

  1. Выходы всех кварцевых датчиков → входы мультиплексора CD4051 (пины Y0–Y7).
  2. Общий выход CD4051 (пин Z) → вход усилителя OPA333.
  3. Выход OPA333 → аналоговый вход ESP32 (пин ADC0, GPIO36).
  4. Управляющие пины CD4051 (S0, S1, S2) → любые цифровые пины ESP32.
  5. Питание: 3.3V от ESP32 для OPA333 и CD4051.

⚠️ Важно: Все компоненты должны быть заземлены на общую шину ESP32. Без качественного заземления вы будете видеть только наводки 50 Гц от сети.

3 Экранировка

S-RADIO чрезвычайно чувствителен к электромагнитным помехам. Без экранировки вы будете «слышать» Wi-Fi, радио и электрическую проводку, а не мысли.

  1. Оберните макетную плату с датчиками в 2–3 слоя алюминиевой фольги.
  2. Соедините фольгу с землёй (GND ESP32).
  3. Оставьте открытой только переднюю сторону датчиков (ту, что направлена на оператора).
  4. Подключите ESP32 к ноутбуку, работающему от батареи (не от сети!).

💻 Этап 2: Программирование ESP32 и Python

4 Прошивка ESP32

Загрузите в ESP32 скетч, который делает следующее:

  1. Циклически опрашивает все датчики через мультиплексор (10 циклов в секунду).
  2. Оцифровывает сигнал (12 бит, частота дискретизации 1 кГц).
  3. Выполняет быстрое преобразование Фурье (FFT) на 512 точках (используйте библиотеку arduinoFFT).
  4. Отправляет спектр (массив из 256 значений) по Wi-Fi на ПК в формате JSON.

💡 Готовый скетч для ESP32: Код ниже выполняет всё необходимое — опрос датчиков, FFT и отправку спектра по Wi-Fi.

// ============================================
// S-RADIO v1.0 — Семантическое Радио
// Скетч для ESP32
// ============================================

#include <WiFi.h>
#include <WiFiUdp.h>
#include <arduinoFFT.h>

// ========== НАСТРОЙКИ Wi-Fi ==========
const char* ssid = "Ваш_WiFi_SSID";       // ← ЗАМЕНИТЕ
const char* password = "Ваш_WiFi_Пароль";  // ← ЗАМЕНИТЕ

// ========== НАСТРОЙКИ UDP ==========
WiFiUDP udp;
const char* serverIP = "192.168.1.100";     // ← IP вашего ПК
const int serverPort = 12345;

// ========== НАСТРОЙКИ АЦП ==========
#define ADC_PIN 36                    // Аналоговый вход (VP)
#define SAMPLES 512                  // Точек для FFT
#define SAMPLING_FREQ 1000           // Частота дискретизации (Гц)

// ========== НАСТРОЙКИ МУЛЬТИПЛЕКСОРА ==========
#define MUX_S0 25
#define MUX_S1 26
#define MUX_S2 27
const int NUM_SENSORS = 5;             // Число датчиков

// ========== МАССИВЫ ДЛЯ FFT ==========
double vReal[SAMPLES];
double vImag[SAMPLES];
arduinoFFT FFT = arduinoFFT(vReal, vImag, SAMPLES, SAMPLING_FREQ);

// ========== УСТАНОВКА ==========
void setup() {
  Serial.begin(115200);
  
  // Настройка пинов мультиплексора
  pinMode(MUX_S0, OUTPUT);
  pinMode(MUX_S1, OUTPUT);
  pinMode(MUX_S2, OUTPUT);
  
  // Подключение к Wi-Fi
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nS-RADIO: Wi-Fi подключён!");
  
  // Настройка АЦП
  analogReadResolution(12);           // 12 бит (0–4095)
  analogSetAttenuation(ADC_11db);      // Диапазон 0–3.3V
}

// ========== ВЫБОР ДАТЧИКА ЧЕРЕЗ МУЛЬТИПЛЕКСОР ==========
void selectSensor(int channel) {
  digitalWrite(MUX_S0, channel & 0x01);
  digitalWrite(MUX_S1, (channel >> 1) & 0x01);
  digitalWrite(MUX_S2, (channel >> 2) & 0x01);
  delayMicroseconds(10); // Стабилизация
}

// ========== ЧТЕНИЕ ДАННЫХ С ДАТЧИКОВ ==========
void readSensors() {
  // Усредняем сигнал со всех датчиков
  for (int i = 0; i < SAMPLES; i++) {
    double sum = 0;
    for (int s = 0; s < NUM_SENSORS; s++) {
      selectSensor(s);
      sum += analogRead(ADC_PIN);
      delayMicroseconds(50);
    }
    vReal[i] = sum / NUM_SENSORS;       // Среднее по датчикам
    vImag[i] = 0;
    delayMicroseconds(1000000 / SAMPLING_FREQ - NUM_SENSORS * 60);
  }
}

// ========== ОТПРАВКА СПЕКТРА ПО Wi-Fi ==========
void sendSpectrum() {
  // Формируем JSON-строку: {"f":[частота1,частота2,...],"a":[амплитуда1,амплитуда2,...]}
  String json = "{\\"f\\":[";
  for (int i = 0; i < SAMPLES/2; i++) {
    if (i > 0) json += ",";
    json += String(i * SAMPLING_FREQ / SAMPLES);
  }
  json += "],\\"a\\":[";
  for (int i = 0; i < SAMPLES/2; i++) {
    if (i > 0) json += ",";
    json += String(vReal[i], 2);
  }
  json += "]}";

  // Отправка по UDP
  udp.beginPacket(serverIP, serverPort);
  udp.print(json);
  udp.endPacket();
}

// ========== ГЛАВНЫЙ ЦИКЛ ==========
void loop() {
  // 1. Читаем сигнал со всех датчиков
  readSensors();
  
  // 2. Выполняем FFT
  FFT.Windowing(FFT_WIN_TYP_HAMMING, FFT_FORWARD);
  FFT.Compute();
  FFT.ComplexToMagnitude();
  
  // 3. Отправляем спектр на ПК
  sendSpectrum();
  
  // 4. Пауза 100 мс (10 отправок в секунду)
  delay(100);
}

⚠️ Не забудьте:

  • Заменить SSID и пароль Wi-Fi на свои.
  • Заменить IP-адрес сервера (serverIP) на IP вашего ноутбука.
  • Установить библиотеку arduinoFFT через менеджер библиотек Arduino IDE.
  • Если у вас другое количество датчиков — изменить NUM_SENSORS.

5 Python-сервер на ПК

На ноутбуке запустите Python-скрипт, который:

  1. Принимает спектры от ESP32 по Wi-Fi (UDP-сервер).
  2. Усредняет спектр от всех датчиков.
  3. Сравнивает со спектрами из библиотеки эталонов методом ближайшего соседа (KNN).
  4. Выводит на экран название распознанного слова и отправляет его на синтезатор речи.

💡 Совет: Для синтеза речи используйте библиотеку pyttsx3 (работает офлайн, не требует интернета). Установка: pip install pyttsx3.

💻 Готовый код Python-сервера для S-RADIO

Ниже приведён полный код сервера, который принимает спектры от ESP32 по Wi-Fi, сравнивает их с библиотекой эталонов и управляет синтезатором речи. Скопируйте его в файл sradio_server.py и запустите.

# ============================================= # S-RADIO Server v1.0 # Принимает спектры от ESP32 по UDP, # распознаёт мысль и озвучивает её. # Требуется: pip install pyttsx3 numpy # ============================================= import socket import json import numpy as np import pyttsx3 from collections import defaultdict # ---------- НАСТРОЙКИ ---------- UDP_IP = "0.0.0.0" # Слушать все интерфейсы UDP_PORT = 12345 # Порт (должен совпадать с ESP32) CONFIDENCE_THRESHOLD = 0.6 # Порог уверенности (0..1) # ---------- БИБЛИОТЕКА ЭТАЛОНОВ ---------- # Загружается из файла library.json # Формат: {"яблоко": [0.1, 0.5, ...], "дом": [0.3, 0.2, ...]} try: with open("library.json", "r", encoding="utf-8") as f: LIBRARY = json.load(f) print(f"[OK] Библиотека загружена. Слов: {len(LIBRARY)}") except FileNotFoundError: print("[!] Файл library.json не найден. Создаю пустую библиотеку.") LIBRARY = {} # ---------- СИНТЕЗАТОР РЕЧИ ---------- engine = pyttsx3.init() engine.setProperty('rate', 150) # Скорость речи engine.setProperty('volume', 0.8) # Громкость # ---------- ФУНКЦИИ ---------- def euclidean_distance(a, b): """Евклидово расстояние между двумя векторами-спектрами.""" return np.sqrt(np.sum((np.array(a) - np.array(b)) ** 2)) def classify_spectrum(input_spectrum): """Находит ближайший эталон в библиотеке методом KNN.""" if not LIBRARY: return None, 0.0 best_word = None best_distance = float('inf') for word, ref_spectrum in LIBRARY.items(): dist = euclidean_distance(input_spectrum, ref_spectrum) if dist < best_distance: best_distance = dist best_word = word # Нормализуем расстояние в уверенность (0..1) # Чем меньше расстояние — тем выше уверенность max_possible_dist = np.sqrt(len(input_spectrum)) # Макс. расстояние для нормировки confidence = 1.0 - (best_distance / max_possible_dist) confidence = max(0.0, min(1.0, confidence)) return best_word, confidence def speak_word(word): """Произносит слово через синтезатор речи.""" print(f"[SPEECH] 🗣️ {word}") engine.say(word) engine.runAndWait() def add_to_library(word, spectrum): """Добавляет (или усредняет) спектр в библиотеку.""" if word in LIBRARY: # Усредняем с существующим old = np.array(LIBRARY[word]) new = np.array(spectrum) LIBRARY[word] = ((old * 0.9 + new * 0.1)).tolist() else: LIBRARY[word] = spectrum # Сохраняем библиотеку на диск with open("library.json", "w", encoding="utf-8") as f: json.dump(LIBRARY, f, ensure_ascii=False, indent=2) print(f"[LIB] Слово '{word}' добавлено/обновлено в библиотеке.") # ---------- ГЛАВНЫЙ ЦИКЛ ---------- sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM) sock.bind((UDP_IP, UDP_PORT)) print(f"[S-RADIO] Сервер запущен на порту {UDP_PORT}. Ожидание спектров от ESP32...") print(f"[S-RADIO] Команды: 'CALIBRATE:слово' — запись эталона, 'RECOGNIZE' — распознавание.") current_mode = "RECOGNIZE" # Режим по умолчанию calibration_word = "" try: while True: data, addr = sock.recvfrom(8192) # Принять UDP-пакет try: message = json.loads(data.decode('utf-8')) except json.JSONDecodeError: # Может быть текстовая команда text = data.decode('utf-8').strip() if text.startswith("CALIBRATE:"): calibration_word = text.split(":", 1)[1] current_mode = "CALIBRATE" print(f"[MODE] Режим КАЛИБРОВКА. Слово: '{calibration_word}'. Жду 50 спектров...") elif text == "RECOGNIZE": current_mode = "RECOGNIZE" print(f"[MODE] Режим РАСПОЗНАВАНИЕ.") continue # Обработка JSON-спектра spectrum = message.get("spectrum", []) if not spectrum: continue if current_mode == "CALIBRATE": add_to_library(calibration_word, spectrum) elif current_mode == "RECOGNIZE": word, confidence = classify_spectrum(spectrum) if word and confidence >= CONFIDENCE_THRESHOLD: print(f"[RECOGNIZE] 🧠 {word} (уверенность: {confidence:.2f})") speak_word(word) elif word: print(f"[RECOGNIZE] 🤔 {word} (уверенность: {confidence:.2f}) — ниже порога, молчу.") except KeyboardInterrupt: print("\n[S-RADIO] Сервер остановлен.") sock.close()

  2. Установите зависимости: pip install pyttsx3 numpy.
  3. Запустите: python sradio_server.py.
  4. Убедитесь, что ESP32 отправляет спектры на тот же порт (12345).

💡 Как записать эталон (режим калибровки):

Отправьте с ESP32 текстовую команду CALIBRATE:яблоко, затем 50 спектров. Сервер автоматически усреднит их и сохранит в библиотеку. Затем отправьте RECOGNIZE для возврата в режим распознавания.

⚠️ Важно: Первый запуск — библиотека пуста. Сначала запишите эталоны для 3–5 слов в режиме калибровки, иначе распознавание всегда будет молчать.

💻 Готовый Python-скрипт для S-RADIO

Скопируйте этот код, сохраните как sradio_server.py и запустите на ноутбуке. Скрипт принимает спектры от ESP32 по Wi-Fi, сравнивает их с эталонами и произносит распознанное слово.

Требования: Python 3.8+, библиотеки numpy, scipy, pyttsx3. Установка: pip install numpy scipy pyttsx3

# ============================================================
#  S-RADIO SERVER v1.0
#  Идеатоника • Семантическое Радио
#  Принимает спектры от ESP32, распознаёт мысли, озвучивает
# ============================================================

import socket
import json
import numpy as np
from scipy.spatial import distance
import pyttsx3
import os

# ========== НАСТРОЙКИ ==========
UDP_IP = "0.0.0.0"          # Принимаем со всех адресов
UDP_PORT = 12345            # Порт должен совпадать с ESP32
LIBRARY_FILE = "library.json"  # Файл с эталонными спектрами

# ========== БИБЛИОТЕКА ЭТАЛОНОВ ==========
if os.path.exists(LIBRARY_FILE):
    with open(LIBRARY_FILE, "r") as f:
        library = json.load(f)
    print(f"✅ Библиотека загружена: {len(library)} слов")
else:
    # Если файла нет — создаём пустую библиотеку
    library = {}
    print("⚠️ Библиотека не найдена. Создана пустая. Нужна калибровка!")

# ========== СИНТЕЗАТОР РЕЧИ ==========
engine = pyttsx3.init()
engine.setProperty('rate', 150)   # Скорость речи (нормально)
engine.setProperty('volume', 0.8) # Громкость

def speak(word):
    print(f"🔊 Произношу: {word}")
    engine.say(word)
    engine.runAndWait()

# ========== РАСПОЗНАВАНИЕ (KNN) ==========
def recognize(spectrum):
    best_word = None
    best_distance = float('inf')
    
    for word, etalon in library.items():
        # Евклидово расстояние между спектрами
        d = distance.euclidean(spectrum, etalon['spectrum'])
        if d < best_distance:
            best_distance = d
            best_word = word
    
    return best_word, best_distance

# ========== ДОБАВЛЕНИЕ В БИБЛИОТЕКУ ==========
def add_to_library(word, spectrum):
    if word in library:
        # Усредняем с существующим
        old = np.array(library[word]['spectrum'])
        new = np.array(spectrum)
        avg = ((old * library[word]['count']) + new) / (library[word]['count'] + 1)
        library[word]['spectrum'] = avg.tolist()
        library[word]['count'] += 1
    else:
        library[word] = {'spectrum': spectrum, 'count': 1}
    
    # Сохраняем библиотеку на диск
    with open(LIBRARY_FILE, "w") as f:
        json.dump(library, f, indent=2)
    print(f"📚 Слово '{word}' добавлено в библиотеку (всего: {len(library)})")

# ========== ОСНОВНОЙ ЦИКЛ ==========
print("📻 S-RADIO Server запущен. Ожидание данных от ESP32...")
print("   Режимы:")
print("   • Отправьте 'calibrate:СЛОВО' — для записи эталона")
print("   • Отправьте спектр — для распознавания")

sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.bind((UDP_IP, UDP_PORT))

while True:
    data, addr = sock.recvfrom(4096)  # Принимаем JSON-пакет
    
    try:
        message = json.loads(data.decode('utf-8'))
    except:
        continue
    
    if 'command' in message:
        # Режим калибровки
        cmd = message['command']
        if cmd == 'calibrate':
            word = message['word']
            spectrum = message['spectrum']
            add_to_library(word, spectrum)
            speak(f"Слово {word} сохранено")
    elif 'spectrum' in message:
        # Режим распознавания
        spectrum = message['spectrum']
        word, dist = recognize(spectrum)
        if word:
            print(f"🎯 Распознано: {word} (дистанция: {dist:.2f})")
            speak(word)
        else:
            print("❓ Библиотека пуста. Сначала проведите калибровку.")

🧪 Этап 3: Калибровка (запись эталонов)

6 Подготовка оператора

  1. Оператор надевает COH-METER 2.0 и входит в состояние Cₛ > 0.7 (медитация 5 минут).
  2. Садится перед матрицей датчиков на расстоянии 30–50 см.
  3. На экране ноутбука появляется изображение объекта (например, яблоко). Оператор смотрит на него 5 секунд.
  4. Оператор закрывает глаза и 10 секунд удерживает мысленный образ, не отвлекаясь.
  5. ESP32 записывает спектр и отправляет на ПК. Процедура повторяется 30–50 раз для каждого слова.

7 Формирование библиотеки эталонов

Для каждого слова (яблоко, дом, вода, мама, страх...) вычисляется усреднённый спектр и его дисперсия. Спектры сохраняются в файл library.json.

Начните с 3–5 слов с максимально разными семантическими частотами. «Яблоко» и «мяч» будут путаться (оба круглые), «мама» и «страх» — нет.

🎤 Этап 4: Тестирование и озвучивание

8 Распознавание в реальном времени

  1. Оператор думает о случайном слове из библиотеки (не произнося его).
  2. S-RADIO записывает спектр, сравнивает с эталонами и выводит результат.
  3. Синтезатор речи произносит распознанное слово.
  4. Проведите 100 попыток и оцените процент правильных распознаваний.

Ожидаемая точность: 60–90% при Cₛ > 0.8. Случайный уровень (для 5 слов): 20%.

💡 Лайфхак: Если точность низкая, попробуйте увеличить Cₛ оператора (медитация перед тестом) или добавить больше датчиков (10 вместо 5).
