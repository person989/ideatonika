🔋 AS-2: ПОДРОБНАЯ СБОРКА

Пошаговое руководство • Умная Зарядная Станция с обратной связью

📖 Что такое AS-2 и чем он отличается от AS-1?

AS-1 (Аккумулятор Смысла) — это простая «банка», которая накапливает Qₛ, когда вы держите на ней руки. Проблема в том, что она не отличает «вы в потоке» от «вы просто сидите с рассеянным умом». В результате 70% времени зарядки может проходить впустую.

AS-2 решает эту проблему с помощью обратной связи. К схеме добавляется ЭЭГ-гарнитура (COH-METER 2.0) и управляемое реле. Когда ваша когерентность Cₛ превышает порог (например, 0.7), реле замыкает цепь, и Qₛ течёт в аккумулятор. Когда Cₛ падает — цепь размыкается.

Результат: за то же время сеанса AS-2 накапливает на 30-50% больше Qₛ, а оператор получает мгновенную визуальную обратную связь (зелёный светодиод = «молодец, продолжай»).

🔨 Этап 1: Сборка электрической части

1 Подготовка реле

Твердотельное реле (SSR-5V) — это электронный «выключатель», который замыкает и размыкает цепь по команде от микроконтроллера. В отличие от механического реле, оно не щёлкает и не создаёт электромагнитных помех.

  1. У реле есть 4 контакта: два — управляющие (подписаны «+» и «-» или «DC»), два — силовые (подписаны «~» или «AC»).
  2. Подключите управляющие контакты к Arduino: «+» реле → пин D13 Arduino, «-» реле → пин GND Arduino.
  3. Силовые контакты реле мы подключим позже — они будут размыкать/замыкать цепь между вашими ладонями и электродом AS-1.

📍 Распиновка реле SSR-5V

    [РЕЛЕ SSR-5V]
     ┌─────────┐
     │ +   -   │ ← Управление (к Arduino: D13 и GND)
     │         │
     │ ~   ~   │ ← Силовая цепь (разрыв провода от ладони к электроду)
     └─────────┘

2 Подключение светодиодов (индикаторов)

Мы сделаем простую цветовую индикацию: зелёный = Cₛ выше порога, идёт зарядка. красный = Cₛ ниже порога, ожидание.

  1. Возьмите зелёный светодиод. У него длинная ножка — это «+» (анод), короткая — «-» (катод).
  2. Подключите короткую ножку (катод) зелёного светодиода к пину GND Arduino.
  3. Подключите длинную ножку (анод) зелёного светодиода через резистор 220 Ом к пину D12 Arduino.
  4. Точно так же подключите красный светодиод: катод → GND, анод через резистор 220 Ом → пин D11 Arduino.

⚠️ Важно: Никогда не подключайте светодиод к Arduino БЕЗ резистора! Без ограничения тока светодиод сгорит мгновенно, а порт Arduino может выйти из строя. Резистор на 220 Ом обязателен.

3 Сборка силовой цепи (самое главное)

Теперь нам нужно «врезать» реле в цепь, по которой Qₛ течёт от ваших ладоней к электроду AS-1.

Как это работает: Вы держите ладони на двух металлических пластинах (или просто на оголённых проводах). Обычно эти пластины напрямую соединены с серебряными электродами внутри AS-1. Мы разрезаем один из этих проводов и вставляем в разрыв силовые контакты реле.

  1. Найдите провод, идущий от серебряного электрода (+) в AS-1 к вашей правой ладони. Разрежьте его посередине. Зачистите концы.
  2. Один зачищенный конец прикрутите к первому силовому контакту реле (одна из клемм «~»).
  3. Второй зачищенный конец прикрутите ко второму силовому контакту реле (вторая клемма «~»).

📍 Силовая цепь (схема)

    [ЛАДОНЬ ПРАВАЯ] ──── [РЕЛЕ (разрыв)] ──── [ЭЛЕКТРОД (+) AS-1]
    
    Реле замкнуто (Cₛ > 0.7) → Qₛ течёт в аккумулятор.
    Реле разомкнуто (Cₛ < 0.7) → Qₛ не тратится впустую.

💡 Почему мы разрываем только ОДИН провод: Для протекания Qₛ (как и электрического тока) нужна замкнутая цепь. Если разорвать один провод — цепь размыкается, и зарядка останавливается. Разрывать оба провода не нужно.

💻 Этап 2: Программирование Arduino

4 Код для Arduino

Arduino будет слушать последовательный порт (Serial) и ждать команды от компьютера. Когда компьютер присылает символ '1' (Cₛ ≥ 0.7) — Arduino замыкает реле и зажигает зелёный светодиод. Когда присылает '0' (Cₛ < 0.7) — размыкает реле и зажигает красный.

📍 Код для Arduino (скопируйте и загрузите)

// Пины
const int RELAY_PIN = 13;   // Реле
const int GREEN_PIN = 12;   // Зелёный светодиод
const int RED_PIN = 11;     // Красный светодиод

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(GREEN_PIN, OUTPUT);
  pinMode(RED_PIN, OUTPUT);
  
  Serial.begin(9600); // Открываем порт для связи с ПК
  
  // На старте — реле разомкнуто, горит красный
  digitalWrite(RELAY_PIN, LOW);
  digitalWrite(GREEN_PIN, LOW);
  digitalWrite(RED_PIN, HIGH);
}

void loop() {
  if (Serial.available() > 0) {
    char command = Serial.read();
    
    if (command == '1') {
      // Cₛ >= 0.7 — ЗАРЯЖАЕМ!
      digitalWrite(RELAY_PIN, HIGH);   // Замкнуть реле
      digitalWrite(GREEN_PIN, HIGH);   // Зелёный горит
      digitalWrite(RED_PIN, LOW);      // Красный гаснет
    }
    else if (command == '0') {
      // Cₛ < 0.7 — ОЖИДАНИЕ
      digitalWrite(RELAY_PIN, LOW);    // Разомкнуть реле
      digitalWrite(GREEN_PIN, LOW);    // Зелёный гаснет
      digitalWrite(RED_PIN, HIGH);     // Красный горит
    }
  }
}
  1. Подключите Arduino к компьютеру по USB.
  2. Откройте Arduino IDE (бесплатная программа).
  3. Скопируйте код выше и вставьте в редактор.
  4. Выберите правильный порт (Инструменты → Порт → COMx) и плату (Инструменты → Плата → Arduino Nano/Uno).
  5. Нажмите «Загрузить» (стрелка вправо).
  6. После загрузки откройте Монитор порта (Инструменты → Монитор порта). Отправьте '1' — реле должно щёлкнуть, загореться зелёный. Отправьте '0' — реле выключится, загорится красный.

5 Скрипт для компьютера (Python)

Теперь нужна программа, которая будет читать Cₛ с ЭЭГ-гарнитуры и отправлять команды '1' или '0' в Arduino.

📍 Python-скрипт (сохраните как as2_controller.py)

import serial
import time

# Настройки порта (замените COM3 на ваш порт Arduino)
PORT = 'COM3'
BAUD = 9600
THRESHOLD = 0.7  # Порог Cₛ для зарядки

# Подключение к Arduino
try:
    arduino = serial.Serial(PORT, BAUD, timeout=1)
    time.sleep(2)  # Пауза на инициализацию
    print(f"✅ Подключено к Arduino на порту {PORT}")
except:
    print(f"❌ Не удалось подключиться к {PORT}")
    exit()

# Функция получения Cₛ (ЗАГЛУШКА — замените на реальный код!)
def get_cs():
    # В реальности здесь должен быть код, читающий данные с Muse/NeuroSky
    # Пока что — просто случайное число для теста
    import random
    return random.uniform(0.3, 0.9)

print("🚀 AS-2 Controller запущен. Начинаем мониторинг Cₛ...")
print(f"Порог срабатывания: Cₛ >= {THRESHOLD}")

while True:
    cs = get_cs()
    timestamp = time.strftime("%H:%M:%S")
    
    if cs >= THRESHOLD:
        arduino.write(b'1')
        print(f"[{timestamp}] Cₛ = {cs:.2f} 🟢 ЗАРЯДКА (реле замкнуто)")
    else:
        arduino.write(b'0')
        print(f"[{timestamp}] Cₛ = {cs:.2f} 🔴 ОЖИДАНИЕ (реле разомкнуто)")
    
    time.sleep(1)  # Проверяем Cₛ раз в секунду

💡 Важно: В реальном проекте функция get_cs() должна читать данные с вашей ЭЭГ-гарнитуры. Для Muse 2 есть библиотека muse-lsl для Python. Для NeuroSky есть pyNeuroSky. Установите их и замените заглушку на реальный код. Если вы используете пульсометр вместо ЭЭГ — найдите библиотеку для вашего браслета.

🧪 Этап 3: Тестирование и калибровка

6 Проверка работы системы

  1. Подключите Arduino к компьютеру по USB. Запустите Python-скрипт.
  2. Убедитесь, что в консоли идут сообщения «Cₛ = ... 🟢 ЗАРЯДКА» или «🔴 ОЖИДАНИЕ».
  3. Проверьте, что при сообщении «ЗАРЯДКА» зелёный светодиод загорается, а красный гаснет.
  4. Проверьте, что при сообщении «ОЖИДАНИЕ» красный светодиод загорается, а зелёный гаснет.
  5. Поднесите руки к контактным пластинам. При зелёном свете вы должны почувствовать лёгкое тепло или покалывание — это Qₛ течёт в аккумулятор.

7 Калибровка порога Cₛ

Порог 0.7 подходит не всем. Если вы новичок, и ваш Cₛ редко поднимается выше 0.5 — поставьте порог 0.5. Если вы опытный медитатор — поставьте 0.85.

Измените строчку в Python-скрипте:

THRESHOLD = 0.5  # Для новичков

Или:

THRESHOLD = 0.85  # Для профи
