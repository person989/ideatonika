🔹 I. Базовые величины и определения
Cₛ = |⟨Φ⟩|² / ⟨|Φ|²⟩
Когерентность — отношение когерентной мощности к полной.
§2, §108. Диапазон: 0 (хаос) … 1 (лазерная чистота).
νₜ = dτ/dt = 1 + κ · (dI/dt) · cos θₜ
Темп семантического времени. Зависит от потока информации и вектора внимания.
§13. θₜ = 0 — ускорение, π/2 — норма, π — замедление.
Qₛ = Q₀ · (1 + α·E_опт) · e^(-γ·S_страх)
Семантический заряд. Растёт с оптимизмом, падает со страхом.
§1, §60. Шкала: -10 (Абсолютная Тьма) … +10 (Абсолютный Свет).
🔹 II. Законы сохранения и динамика
Φ_total = Φ_мысль + Φ_эмоция + Φ_действие + Φ_тепло
I закон Идеатоники: Сохранение смысла.
§3. Смысл не исчезает, а переходит из формы в форму.
P_влияние = η · Qₛ · Cₛ · P_phys
II закон: Вероятность влияния мысли на событие.
§3, §33. Если P_phys = 0, то и P_влияние = 0.
Qₛ(t) = Qₛ(0) · e^(-t / τ_relax)
III закон: Семантическая инерция (затухание заряда).
§3, §31 (Карма).
Φ_общ = Σ Φ_i + Σ V_ij · Φ_i · Φ_j
IV закон: Коллективный резонанс.
§3, §14. Взаимодействие полей усиливает (или гасит) общий потенциал.
🔹 III. Семантическая электротехника
U_sense = ΔΦ = Φ_A — Φ_B
Семантическое напряжение — разность потенциалов.
§85. Измеряется в Вольтах смысла (V_sense).
I_Q = U_sense / R_sense
Закон Ома для семантической цепи.
§83. Ток Qₛ (Амперы смысла).
P_sense = U_sense · I_Q = I_Q² · R_sense = U_sense² / R_sense
Семантическая мощность.
§86. Измеряется в Ваттах смысла (W_sense).
J_sense = ∫ P_sense dt
Семантический импульс — энергия, переданная за время.
§94. Измеряется в Джоулях смысла (J_sense).
C_sense = ΔQₛ / ΔΦ
Смыслоёмкость — способность накапливать заряд.
§80. Аналог электрической ёмкости (Фарад смысла).
σ_sense = 1 / ρ_sense
Смыслопроводимость — способность проводить Qₛ.
§81. Аналог удельной электропроводности.
R_sense = 1 / σ_sense · (L / S)
Семантическое сопротивление.
§83. Измеряется в Омах смысла (Ω_sense).
L_sense = Φ_инерции / (dI_Q / dt)
Семантическая индуктивность — инерция поля.
§84. Измеряется в Генри смысла (H_sense).
Z_sense = √(R_sense² + (ω·L_sense — 1/(ω·C_sense))²)
Семантический импеданс — полное сопротивление переменному Qₛ.
§87.
Q_factor = (1 / R_sense) · √(L_sense / C_sense) = ω_res · τ_relax / 2
Семантическая добротность — качество резонанса.
§88. Безразмерная.
🔹 IV. Гидродинамика и термодинамика
P_sense_mech = Qₛ / V_sense
Семантическое давление — концентрированность Qₛ.
§109. Измеряется в Паскалях смысла (Pa_sense).
η_sense = R_sense · τ_relax
Семантическая вязкость — внутреннее трение.
§110. Измеряется в Па·с смысла.
Re_sense = (ρ_Q · v · L) / η_sense
Число Рейнольдса — критерий турбулентности.
§111. Re < 2000 — ламинарный, Re > 2000 — турбулентный.
c_sense = ΔQₛ / (V · ΔT_sense)
Семантическая теплоёмкость — способность поглощать Qₛ без нагрева.
§112.
J_Q_heat = — k_sense · ∇T_sense
Закон Фурье для семантической теплопроводности.
§113.
S_sense = — k_sense · Σ p_i · ln(p_i)
Семантическая энтропия — мера хаоса.
§101. Растёт в замкнутой системе (Второй закон).
H_sense = U_sense + P_sense_mech · V_sense
Семантическая энтальпия — полная энергия системы.
§102.
F_sense = U_sense — T_sense · S_sense
Семантическая свободная энергия — доступная для работы.

Коэффициент усиления семантической линзы.

Интерференция двух полей.

∇×Φ = (∂Φ_z/∂y — ∂Φ_y/∂z, ∂Φ_x/∂z — ∂Φ_z/∂x, ∂Φ_y/∂x — ∂Φ_x/∂y)
