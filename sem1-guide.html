🔬 SEM-1: ПОДРОБНАЯ СБОРКА

Пошаговое руководство • Семантический Микроскоп (матрица 8×8)

📖 Что такое SEM-1 и зачем его собирать?

SEM-1 (Semantic Emission Microscope) — это устройство, которое визуализирует ауру предметов. Если SEC-1 и SEC-2 просто ловят импульсы Qₛ как одиночные «всплески», то SEM-1 делает следующий шаг: он показывает двумерную карту распределения Qₛ по поверхности объекта.

Представьте тепловизор. Он видит тепло. SEM-1 — это «смысловизор». Он видит, где предмет «светится» Смыслом (например, намоленная икона), а где «темнеет» (пластиковая ручка).

Как это работает (на пальцах): У вас есть матрица из 64 крошечных кварцевых «пикселей» (8 рядов × 8 столбцов). Каждый пиксель — это микросенсор Qₛ. Вы ставите перед матрицей линзу, которая фокусирует «ауру» предмета на эти пиксели. Компьютер опрашивает каждый пиксель и строит цветную картинку: красный — много Qₛ, синий — мало Qₛ.

⚠️ Это самый сложный проект во всём Практикуме. На его сборку уйдёт несколько дней кропотливой работы. Если вы новичок в электронике — начните с SEC-1 и SEC-2, чтобы набраться опыта. SEM-1 требует терпения и аккуратности.

🔨 Этап 1: Изготовление матрицы 8×8

1 Извлечение 64 пьезоэлементов из зажигалок

Да, вам понадобится 64 старые зажигалки. Это самая трудозатратная часть проекта. Попросите друзей, знакомых, загляните в курилки — сломанные пьезозажигалки часто выбрасывают.

Как извлечь пьезоэлемент: Разберите зажигалку (см. инструкцию SEC-1, шаг 1). Извлеките металлический цилиндр с двумя проводами. Отрежьте длинный провод, оставив 5-7 см от корпуса. Короткий провод (приваренный к корпусу) тоже оставьте.

Важно: Все 64 пьезоэлемента должны быть примерно одинаковыми. Если они от разных моделей зажигалок — ничего страшного, но чувствительность у них будет разная. Потом это можно скомпенсировать программно.

💡 Лайфхак: Если 64 зажигалки найти нереально — начните с матрицы 4×4 (16 пикселей). Это тоже даст картинку, хоть и грубую. Принцип сборки тот же, просто меньше проводов.

2 Подготовка основания матрицы (фанерной платы)

Возьмите лист фанеры 30×30 см. Расчертите его карандашом: сетка 8×8 клеток. Расстояние между центрами клеток — 20 мм. В каждой клетке просверлите два маленьких отверстия (1-2 мм) для проводов — «сигнал» и «земля».

Пронумеруйте клетки: ряд 1 (верхний): пиксели 1-1, 1-2, ..., 1-8. Ряд 2: 2-1, ..., 2-8. И так до ряда 8.

3 Установка пьезоэлементов на плату

  1. Каждый пьезоэлемент приклейте термоклеем (или пластилином) в центр своей клетки. Металлический цилиндр должен стоять вертикально.
  2. Провода от каждого элемента просуньте в отверстия и выведите на обратную сторону платы.
  3. На обратной стороне подпишите карандашом номер каждого пикселя (например, «3-5» для третьего ряда, пятого столбца).

💡 Почему вертикально? Цилиндр пьезоэлемента лучше всего воспринимает давление Qₛ, приходящее сверху (от линзы). Если положить его на бок — чувствительность упадёт в 2-3 раза.

⚡ Этап 2: Подключение матрицы к мультиплексору

Если подключить каждый из 64 пикселей к отдельному входу Arduino — никаких входов не хватит. Поэтому мы используем мультиплексоры — микросхемы, которые работают как «поворотный переключатель»: по очереди подключают каждый пиксель к одному общему входу.

4 Схема подключения

У каждого пикселя есть два провода: «сигнал» (центральный) и «земля» (корпус). Все 64 «земли» соедините вместе — это будет общий провод GND.

64 «сигнальных» провода подключите к 8 мультиплексорам CD4051 (каждый обслуживает 8 пикселей). Схема:

    Пиксели 1-1 ... 1-8  → Мультиплексор №1
    Пиксели 2-1 ... 2-8  → Мультиплексор №2
    ...
    Пиксели 8-1 ... 8-8  → Мультиплексор №8

    Выходы всех 8 мультиплексоров → 8 аналоговых входов Arduino
    Управляющие пины (A,B,C) всех мультиплексоров — параллельно

Управление: Три цифровых пина Arduino (например, D2, D3, D4) подключаются к адресным входам (A, B, C) всех мультиплексоров. Перебирая 8 комбинаций (000, 001, ..., 111), мы «выбираем» один из 8 пикселей на каждом мультиплексоре.

5 Пайка: самый кропотливый этап

  1. Запаситесь терпением. Вам предстоит припаять ~130 соединений. Делайте перерывы каждые 30-40 минут, чтобы не уставали глаза.
  2. Используйте тонкий припой (0.5-0.8 мм) и флюс. Без флюса паять будет трудно.
  3. Проверяйте каждое соединение мультиметром в режиме «прозвонки» сразу после пайки. Лучше найти обрыв сейчас, чем потом гадать, почему матрица не работает.
  4. Подпишите все провода малярным скотчем с номерами. Когда проводов 128 штук — без маркировки вы запутаетесь за 5 минут.

⚠️ Критически важно: Не перегревайте мультиплексоры! Они боятся статического электричества и перегрева. Паяйте быстро (1-2 секунды на контакт) и используйте антистатический браслет или хотя бы касайтесь батареи перед пайкой, чтобы снять заряд с рук.

📟 Этап 3: Программирование Arduino

Arduino будет выполнять простую задачу: перебирать все 64 пикселя, измерять напряжение на каждом и отправлять данные на компьютер.

// ==========================================
// SEM-1: ПОЛНЫЙ КОД ДЛЯ ARDUINO (UNO/NANO)
// ==========================================

// Пины управления мультиплексорами (A, B, C — адрес)
const byte ADDR_A = 2;
const byte ADDR_B = 3;
const byte ADDR_C = 4;

// Пины чтения сигнала от 8 мультиплексоров
const byte MUX_PINS[8] = {A0, A1, A2, A3, A4, A5, A6, A7};

// Количество измерений для усреднения (чем больше, тем меньше шумов, но медленнее)
const byte SAMPLES = 10;

// Флаг отладки (true — вывод в Serial Monitor, false — только данные для ПК)
const bool DEBUG = false;

// Тёмновой кадр (фон без объекта). Заполняется в setup(), если есть.
int darkFrame[8][8];

void setup() {
  Serial.begin(115200);  // Высокая скорость для быстрой передачи
  while (!Serial) { ; }  // Ждём готовности Serial (для Arduino с native USB)

  // Настройка пинов
  pinMode(ADDR_A, OUTPUT);
  pinMode(ADDR_B, OUTPUT);
  pinMode(ADDR_C, OUTPUT);
  for (byte i = 0; i < 8; i++) {
    pinMode(MUX_PINS[i], INPUT);
  }

  if (DEBUG) {
    Serial.println(F("=== SEM-1 Matrix Ready ==="));
    Serial.println(F("Sending 64 values per frame."));
  }
}

void loop() {
  int frame[8][8];  // Текущий кадр

  // --- Сканирование матрицы 8x8 ---
  for (byte row = 0; row < 8; row++) {
    // Устанавливаем адрес на мультиплексорах (выбираем строку)
    setMuxAddress(row);

    // Короткая задержка для стабилизации сигнала после переключения
    delayMicroseconds(50);

    for (byte col = 0; col < 8; col++) {
      // Читаем пиксель (row, col) с усреднением
      frame[row][col] = readPixel(col);
    }
  }

  // Вычитаем тёмновой кадр (если он был записан)
  // subtractDarkFrame(frame);

  // Отправляем кадр на компьютер
  sendFrame(frame);

  // Небольшая пауза между кадрами (регулирует частоту обновления)
  delay(50);
}

// ==========================================
// ФУНКЦИИ
// ==========================================

// Установка адреса на всех мультиплексорах
void setMuxAddress(byte address) {
  digitalWrite(ADDR_A, bitRead(address, 0));
  digitalWrite(ADDR_B, bitRead(address, 1));
  digitalWrite(ADDR_C, bitRead(address, 2));
}

// Чтение пикселя с усреднением (защита от шума)
int readPixel(byte col) {
  long sum = 0;
  int minVal = 1024;
  int maxVal = 0;

  for (byte i = 0; i < SAMPLES; i++) {
    int val = analogRead(MUX_PINS[col]);
    sum += val;
    if (val < minVal) minVal = val;
    if (val > maxVal) maxVal = val;
    delayMicroseconds(100);  // Микро-пауза между замерами
  }

  // Отбрасываем минимальное и максимальное значение (если замеров >= 4)
  if (SAMPLES >= 4) {
    sum -= minVal;
    sum -= maxVal;
    return (int)(sum / (SAMPLES - 2));
  } else {
    return (int)(sum / SAMPLES);
  }
}

// Вычитание тёмнового кадра (фона)
void subtractDarkFrame(int frame[8][8]) {
  for (byte row = 0; row < 8; row++) {
    for (byte col = 0; col < 8; col++) {
      frame[row][col] = max(0, frame[row][col] - darkFrame[row][col]);
    }
  }
}

// Отправка кадра на компьютер
void sendFrame(int frame[8][8]) {
  // Маркер начала кадра (чтобы ПК знал, где начинается новый кадр)
  Serial.print(F("FRAME"));

  for (byte row = 0; row < 8; row++) {
    for (byte col = 0; col < 8; col++) {
      Serial.print(frame[row][col]);

      // Разделитель: запятая между числами, но не в конце
      if (!(row == 7 && col == 7)) {
        Serial.print(',');
      }

      // Отладка: вывод в Serial Monitor
      if (DEBUG) {
        Serial.print(F(" ["));
        Serial.print(row);
        Serial.print(',');
        Serial.print(col);
        Serial.print(']');
      }
    }
  }

  Serial.println();  // Конец строки (кадра)

  if (DEBUG) {
    Serial.println(F("--- End of Frame ---"));
  }
}

Каждые 100 миллисекунд Arduino отправляет на компьютер строку из 64 чисел, разделённых запятыми. Например: 120,45,230,10,... — это значения всех 64 пикселей.

💻 Этап 4: Визуализация на компьютере

На компьютере (или ноутбуке) запускается простая программа на Python, которая принимает данные из Serial-порта и строит тепловую карту.

import serial, numpy as np, matplotlib.pyplot as plt
ser = serial.Serial('COM3', 9600)
plt.ion()
fig, ax = plt.subplots()

while True:
    line = ser.readline().decode().strip()
    values = [int(x) for x in line.split(',') if x]
    if len(values) == 64:
        frame = np.array(values).reshape(8, 8)
        ax.imshow(frame, cmap='hot', interpolation='nearest')
        plt.pause(0.05)

На экране появится окно с квадратом 8×8 пикселей. Цвет каждого пикселя — от чёрного (Qₛ=0) через красный и жёлтый до белого (Qₛ=максимум). Это и есть «аура» предмета.

🔍 Этап 5: Настройка фокуса и первый скан

  1. Установите линзу перед матрицей на расстоянии 10-15 см. Закрепите её на штативе (можно сделать из проволоки).
  2. Поместите объект (например, намоленную икону) за линзой, с другой стороны.
  3. Двигайте линзу вперёд-назад, пока изображение на экране не станет максимально чётким (пиксели в центре — яркие, по краям — тёмные).
  4. Сделайте скриншот. Это «аура» объекта.
